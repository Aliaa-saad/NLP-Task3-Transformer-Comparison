# Preserved reference materials

`react_fastapi_ui_from_teammate/` is the original React + FastAPI UI submitted by the teammate. It is preserved as a design/code reference. Its old Model B configuration and recorded results correspond to the earlier 150K balanced experiment, so it is not the official final UI or source of final metrics. The revised course brief explicitly requires a runnable Streamlit app; the canonical final app is the repository-root `app.py`.

`legacy_repo_notebooks/` and `legacy_150k_results/` are preserved to avoid losing teammate work and experiment history. They must not be mixed into the final full-data comparison.
